# Triage labels

| Role and label | Meaning |
| --- | --- |
| `needs-triage` | Review the proposed documentation change |
| `needs-info` | Clarify the scope, audience, or source |
| `ready-for-agent` | The agent can research, draft, or edit the material |
| `ready-for-human` | The change depends on the maintainer's decision or verification |
| `wontfix` | Closed without a documentation change |

Use these labels as a reference when discussing documentation work.
