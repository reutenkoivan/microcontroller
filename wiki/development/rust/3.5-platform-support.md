# 3.5. Підтримка ESP32, STM32, Raspberry Pi Pico та Nordic nRF

[До змісту](../../../README.md#зміст)

Щоб оцінити підтримку платформи, знайди точний чип у документації HAL. Потім перевір підтримку потрібної периферії та наявність прикладів для плати. [Апаратні платформи](../../1-hardware-platforms.md)

| Платформа | На що звернути увагу |
| --- | --- |
| **ESP32** | `esp-hal` підходить для прошивок `no_std`. Для підтримуваних цілей є шлях через ESP-IDF зі стандартною бібліотекою Rust. Перевір наявність потрібних Wi-Fi чи Bluetooth можливостей для конкретної моделі й вибраного набору бібліотек. [esp-rs](https://docs.espressif.com/projects/rust/), [Апаратні варіанти ESP32](https://docs.espressif.com/projects/rust/book/introduction/hardware-overview.html), [Цілі ESP-IDF](https://doc.rust-lang.org/rustc/platform-support/esp-idf.html) |
| **STM32** | Документація `embassy-stm32` описує налаштування для окремих чипів. Для перенесення прошивки звір потрібні таймери, канали DMA та доступні виводи периферії. [embassy-stm32](https://docs.embassy.dev/embassy-stm32/) |
| **Raspberry Pi Pico** | `embassy-rp` охоплює RP2040 і RP235x. Pico має RP2040 із Cortex-M0+, а Pico 2 використовує RP2350 з можливістю вибору Cortex-M33 або Hazard3 RISC-V. PIO дає змогу реалізувати спеціалізовані інтерфейси вводу-виводу на рівні периферії. [Embassy Book](https://embassy.dev/book/), [Мікроконтролери Raspberry Pi](https://www.raspberrypi.com/documentation/microcontrollers/microcontroller-chips.html) |
| **Nordic nRF** | `embassy-nrf` надає HAL для підтримуваних чипів Nordic. Для Bluetooth LE окремо перевір сумісність радіоконтролера й Bluetooth-стека з конкретним чипом. nRF52840 DK — приклад плати з підтримкою Bluetooth LE та вбудованим налагоджувачем. [Embassy Book](https://embassy.dev/book/), [nRF52840 DK](https://www.nordicsemi.com/Products/Development-hardware/nRF52840-DK) |

[Середовище розробки](3.1-development-environment.md) описує типовий набір інструментів для цих плат.
