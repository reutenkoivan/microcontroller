# 3. Rust для мікроконтролерів

[До змісту](../../../README.md#зміст)

Модель володіння Rust допомагає перевіряти доступ до даних і периферії під час компіляції. Наприклад, бібліотека може видати один об’єкт для конкретного таймера, а застосунок — передати його задачі, яка ним керує. Бібліотеки для роботи з регістрами, таймерами й перериваннями залежать від мікроконтролера. [Rust Book про володіння](https://doc.rust-lang.org/book/ch04-01-what-is-ownership.html), [Embedded Rust Book про периферію](https://docs.rust-embedded.org/book/start/registers.html)

Почни із [середовища розробки](3.1-development-environment.md) для своєї плати. Для доступу до датчика чи таймера розберися, як [HAL працює з периферією](3.3-peripherals-embedded-hal.md). Якщо прошивка має одночасно чекати на кілька незалежних подій, дивись [переривання й асинхронність](3.4-interrupts-async-embassy.md). Загальні принципи планування задач і дедлайнів описано в розділі [«RTOS для мікроконтролерів»](../../2-rtos.md).
